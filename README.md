# Solana Token Monitor

An open-source monitoring and alerting tool for the Solana ecosystem.

The goal of this project is to provide a simple way to monitor Solana tokens, track market and liquidity changes, detect notable activity, and generate alerts.

## Planned Features

- Solana token monitoring
- Price and liquidity tracking
- New-token detection
- Configurable alerts
- Wallet activity monitoring
- Risk indicators
- Telegram/Discord alert support
- Lightweight setup suitable for low-powered computers
- Open-source and free to use

## Project Status

🚧 Early development.

The project has recently been started and the initial monitoring system is currently being developed.
